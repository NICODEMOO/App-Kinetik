# KINETIK AI

Aplicación web móvil de medición y seguimiento de rango de movimiento.

## Abrir desde el celular

La versión web se publica automáticamente con GitHub Pages desde la rama `main`.

## Construir la APK Android

El workflow [Build APK](/.github/workflows/build.yml) genera `app-debug.apk` y lo publica como artefacto descargable en GitHub Actions.
